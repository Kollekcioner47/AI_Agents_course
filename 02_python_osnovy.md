## ЧАСТЬ 1. ТЕОРИЯ

### ШАГ 1. ПЕРЕМЕННАЯ — ИМЕНОВАННАЯ КОРОБКА

Программа хранит данные в переменных. Переменная — это именованная
коробка: в неё кладут значение, а потом достают его, назвав коробку
по имени.

```python
day1 = 320
```

Знак «=» здесь не равенство, а ПРИСВАИВАНИЕ: «положи в коробку с
именем day1 значение 320». Слева всегда имя коробки, справа — то, что
кладём.

Имя выбираете вы, по трём правилам:

  * только буквы, цифры и подчёркивание, начинается с буквы;
  * без пробелов: не total sum, а total_sum;
  * осмысленно: total понятнее, чем t.

Достать значение просто — назовите имя:

```python
print(day1)
```

Покажет 320. Если имя ни разу не присваивали, Python сообщит NameError —
его разберём в конце занятия.

ЗАПОМНИТЕ: переменная хранит значение, а не формулу. После
day1 = 320 в коробке лежит 320, пока вы не положите туда новое значение.

### ШАГ 2. ТИПЫ ДАННЫХ: СТРОКА, ЧИСЛО, ЛОГИЧЕСКОЕ

У каждого значения есть ТИП. От типа зависит, что с ним можно делать.
Четыре типа, которые нужны сегодня:

  * str — строка, текст: "Алексей", "3000". Всегда в кавычках.
  * int — целое число: 3, -7, 3000. Без кавычек.
  * float — дробное число: 2.5, -0.75. С точкой.
  * bool — логическое: True или False (ровно так, с большой буквы).

Тип можно спросить у Python:

```python
print(type(320))
print(type("320"))
print(type(3.14))
print(type(True))
```

<class 'int'>
<class 'str'>
<class 'float'>
<class 'bool'>

Главное отличие: "320" — строка, а 320 — число. Строку нельзя складывать
с числом, поэтому тип важно различать. Число 3 и строка "3" выглядят
похоже, но это разные вещи.

ЗАПОМНИТЕ: кавычки — признак строки. Всё, что в кавычках, Python считает
текстом, даже если внутри цифры.

### ШАГ 3. PRINT, INPUT И F-СТРОКИ

print выводит значение на экран. Внутри скобок может быть строка, число
или переменная:

```python
print("Привет!")
print(320)
print(day1)
```

Можно передать несколько значений через запятую — Python выведет их
через пробел:

```python
print("Всего:", 320)
```

Всего: 320

input спрашивает у пользователя и возвращает то, что он ввёл. В скобках
пишут подсказку — её видно перед вводом:

```python
name = input("Как вас зовут? ")
```

Программа остановится, покажет подсказку и будет ждать, пока пользователь
напечатает ответ и нажмёт Enter.

ОСТОРОЖНО: input ВСЕГДА возвращает строку. Даже если пользователь ввёл
«3000», в переменной лежит строка "3000", а не число. Чтобы считать,
нужен перевод: int("3000") даёт число 3000, float("2.5") — число 2.5.
Без перевода сложение упадёт с ошибкой TypeError.

f-строка вставляет значения прямо в текст. Перед кавычками ставят букву
f, значения пишут в фигурных скобках:

```python
name = "Алексей"
print(f"Привет, {name}!")
```

Привет, Алексей!

ЗАПОМНИТЕ: input → всегда str; для счёта — int() или float(). f-строка —
самый удобный способ собрать текст с переменными.

### ШАГ 4. УСЛОВИЯ: IF / ELIF / ELSE

Условие заставляет программу выбрать, какую ветку выполнить. Пишется
так:

```python
limit = 3000
spend = 3500
if spend > limit:
    print("Превышен лимит")
elif spend == limit:
    print("Ровно в лимит")
else:
    print("В норме")
```

Python проверяет условия сверху вниз и выполняет ПЕРВУЮ подошедшую
ветку, остальные пропускает. else срабатывает, когда не подошло ни одно
условие. Веток elif может быть сколько угодно, else — одна и последняя.

Операторы сравнения:

  * == — равно (два знака! один «=» — это присваивание);
  * != — не равно;
  * < — меньше;  > — больше;
  * <= — меньше или равно;  >= — больше или равно.

Несколько условий соединяют словами:

  * and — «и»: оба условия верны;
  * or — «или»: хотя бы одно верно.

```python
age = 25
if age >= 18 and age < 65:
    print("Взрослый")
```

Взрослый

После строки с if обязательны двоеточие и отступ в следующей строке.
Отступ — это 4 пробела: он показывает Python, какой код относится к этой
ветке.

ЗАПОМНИТЕ: == сравнивает, = присваивает. Их путают чаще всего, и это
самая частая ошибка новичка.

### ШАГ 5. ЦИКЛ FOR И НАКОПЛЕНИЕ СУММЫ

Цикл for повторяет блок кода для каждого элемента списка. Список — это
несколько значений в квадратных скобках через запятую:

```python
costs = [150, 640, 320, 90, 500]
```

Переберём его:

```python
for cost in costs:
    print(cost)
```

Python по очереди кладёт каждый элемент в переменную cost и выполняет
блок с отступом. Вывод — пять строк:

150
640
320
90
500

range(5) даёт числа от 0 до 4 — тоже удобно для цикла:

```python
for i in range(5):
    print(i)
```

0
1
2
3
4

Чтобы сложить все элементы, заводят переменную-аккумулятор: до цикла в
ней 0, внутри цикла к ней прибавляют каждый элемент:

```python
total = 0
for cost in costs:
    total = total + cost
print(total)
```

1700

ЗАПОМНИТЕ: аккумулятор создают ДО цикла и обнуляют. Прибавление внутри
цикла повторяется столько раз, сколько элементов в списке.

## ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

### ПРОБЛЕМА: NameError: name 'day1' is not defined

Переменную использовали раньше, чем присвоили, либо в имени опечатка.
Проверьте, что переменной присвоено значение ДО того, как её читают, и
что имя везде написано одинаково: day1 в одном месте и dayl (с буквой l)
в другом — это разные имена.

### ПРОБЛЕМА: TypeError: can only concatenate str (not "int") to str

Складываете строку с числом. Почти всегда причина — input: он вернул
строку, а вы прибавили её к числу. Оберните ввод в int() или float():

```python
spend = int(input("Сумма: "))
```

### ПРОБЛЕМА: IndentationError: expected an indented block

После строки с if или for нет отступа. Всё, что относится к ветке или
циклу, должно начинаться с 4 пробелов. Добавьте отступ в строке, идущей
после if/for, и проверьте, что он одинаковый во всём блоке.

### ПРОБЛЕМА: SyntaxError: invalid syntax

Пропущено двоеточие после if/elif/else/for, либо не закрыта скобка или
кавычка. Сверьте строку с примером: в конце строки условия должно стоять
двоеточие, у каждой открывающей скобки — парная закрывающая.

### ПРОБЛЕМА: программа спрашивает, но непонятно, куда вводить

input остановил программу и ждёт ввод в терминале. Щёлкните в нижнюю
часть редактора (терминал), напечатайте ответ и нажмите Enter. Если
программа «висит» — вы просто не ввели значение, это не ошибка.
