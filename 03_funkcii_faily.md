## ЧАСТЬ 1. ТЕОРИЯ

### ШАГ 1. ЗАЧЕМ НУЖНА ФУНКЦИЯ

Представьте, что ассистенту нужно десять раз поздороваться с разными
людьми. Без функции вы напишете десять почти одинаковых строк:

```python
print("Привет, Алексей!")
print("Привет, Мария!")
print("Привет, Игорь!")
```

Работает, но это копирование: поменяли слово «Привет» на «Здравствуй» —
правите три строки, а не одну. Функция решает эту проблему. Функция —
это именованный кусок кода, который принимает входные данные
(параметры), что-то с ними делает и возвращает результат.

```python
def greet(name):
    return "Привет, " + name + "!"
```

Разберём по частям:

  * def — ключевое слово, с него начинается любая функция;
  * greet — имя функции, придумываете вы (глагол, понятный сразу);
  * (name) — параметр: место, куда при вызове подставят значение;
  * return — что функция отдаёт наружу в качестве результата.

Вызывают функцию по имени, передавая аргумент в скобках:

```python
print(greet("Алексей"))
```

Программа напечатает:

```python
Привет, Алексей!
```

ЗАПОМНИТЕ: функция приносит пользу, когда один и тот же код нужен
много раз. Написали один раз — вызываете сколько угодно. А если код
встречается в программе один-единственный раз, функция ему не нужна.

### ШАГ 2. СТРОКИ: РАЗБИРАЕМ НА ЧАСТИ

Строка в Python — это текст в кавычках. У строки есть методы — встроенные
действия, которые она умеет выполнять. Метод вызывают через точку.
Четыре метода, которые нужны ассистенту каждый день:

  * split(разделитель) — режет строку на части и возвращает список;
  * strip() — убирает пробелы и переносы строк по краям;
  * replace(старое, новое) — заменяет один кусок текста другим;
  * lower() — делает все буквы строчными.

Самый важный для нас — split. Возьмём строку из выписки, где части
разделены точкой с запятой:

```python
line = "03.09.2026;-1284.50;PYATEROCHKA 1234"
parts = line.split(";")
print(parts)
```

Программа напечатает:

```python
['03.09.2026', '-1284.50', 'PYATEROCHKA 1234']
```

Строка разрезалась на список из трёх частей. К каждой части можно
обратиться по номеру, который начинается с нуля:

```python
print(parts[0])   # дата
print(parts[2])   # описание
```

Это называется индексацией: parts[0] — первая часть, parts[1] — вторая,
parts[2] — третья. Именно так ассистент достанет из строки выписки
дату, сумму и описание.

### ШАГ 3. ЧТЕНИЕ ФАЙЛА

Файл на диске программа читает целиком или построчно. Самый удобный
способ — модуль pathlib из стандартной библиотеки:

```python
from pathlib import Path

text = Path("files/03_funkcii_faily/primer.txt").read_text(encoding="utf-8")
```

Path("...") — это путь к файлу. Метод read_text() читает весь файл
и возвращает его как одну большую строку. Чтобы получить список строк,
эту строку режут по переносам:

```python
lines = text.splitlines()
print(len(lines))
```

Если в primer.txt десять строк, программа напечатает:

```python
10
```

Почему encoding="utf-8"? В файле есть русские буквы, а Python на Windows
без явной кодировки может прочитать файл в другой и упасть с ошибкой
UnicodeDecodeError. Правило: текст на русском — всегда encoding="utf-8".

Другой способ — open(), возвращающий список строк (каждая с "\n" на конце):

```python
with open("files/03_funkcii_faily/primer.txt", encoding="utf-8") as f:
    lines = f.readlines()
```

Мы будем пользоваться read_text() — он короче и понятнее.

### ШАГ 4. ЗАПИСЬ ФАЙЛА

Записать результат так же просто, как прочитать. У Path есть метод
write_text(), который принимает строку и кладёт её в файл:

```python
from pathlib import Path

Path("result.txt").write_text("03.09.2026;PYATEROCHKA 1234\n", encoding="utf-8")
```

Если файла result.txt нет, Python создаст его. Если файл уже есть,
write_text() перезапишет его целиком — старое содержимое пропадёт
без предупреждения.

ОСТОРОЖНО: поэтому результат пишем только в новый файл, а исходники
курса (primer.txt и другие) держим только для чтения.

### ШАГ 5. СКЛЕЙКА: ЧИТАЕМ → ОБРАБАТЫВАЕМ → ПИШЕМ

Теперь соберём всё в одну цепочку — это и есть скелет будущего парсера
выписок:

  1. читаем файл методом read_text();
  2. режем текст на строки методом splitlines();
  3. каждую строку разбираем функцией parse_line;
  4. из частей собираем нужное и копим в список;
  5. записываем список в новый файл методом write_text().

Цикл делает всю работу: берёт каждую строку, разбирает её функцией
parse_line, достаёт дату (parts[0]) и описание (parts[2]), склеивает
их и копит в список, который join() собирает в текст, а write_text()
записывает в result.txt. Полный код этой цепочки — в задании 3.

ЗАПОМНИТЕ порядок: сначала читаем, потом обрабатываем, потом пишем.
Никогда не пишем в файл, который ещё читаем.

## ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

### ПРОБЛЕМА: FileNotFoundError — «нет такого файла или каталога»

Программа не нашла primer.txt. Значит, путь в Path("...") не совпадает
с настоящим расположением файла. Проверьте две вещи: что файл лежит
в папке files/03_funkcii_faily внутри папки assistant, и что вы
запускаете программу из папки assistant, а не из другой. Путь в коде
считается от того места, откуда запущен Python.

### ПРОБЛЕМА: UnicodeDecodeError при чтении файла

Python не смог разобрать русские буквы — почти всегда потому, что не
указана кодировка. Добавьте encoding="utf-8" в read_text() и в
open():

```python
Path("files/03_funkcii_faily/primer.txt").read_text(encoding="utf-8")
```

Без этого параметра на Windows Python может читать файл в чужой
кодировке и падать.

### ПРОБЛЕМА: функция возвращает None

Вы вызвали parse_line, а на экране None. Значит, в функции забыли
return: она что-то сделала внутри, но ничего не отдала наружу. Проверьте,
что в функции есть строка return, а вызов вы печатаете: print(parse_line(...)).

### ПРОБЛЕМА: IndentationError внутри функции

Строка «IndentationError: expected an indented block» означает, что
у строки после def нет отступа или отступы сбиты. Тело функции должно
начинаться с четырёх пробелов, а внутри цикла for — ещё с четырёх.
Выровняйте отступы в редакторе и не смешивайте пробелы с клавишей Tab.

### ПРОБЛЕМА: записался пустой файл result.txt

Скорее всего, вы запустили программу, которая только читала, но не
сохраняла, либо запись стояла до заполнения списка out. Убедитесь, что
write_text() вызывается ПОСЛЕ цикла, когда список out уже собран, и что
в write_text() передаётся сам текст, а не пустая строка. Сохраните файл
с кодом (Ctrl+S) и запустите заново.
