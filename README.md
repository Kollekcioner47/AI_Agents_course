# Личный ИИ-помощник — учебный курс

Практический курс по созданию личного ИИ-помощника **с нуля, на Python**.
Слушатель без опыта программирования шаг за шагом собирает собственного
мультиагентного ассистента: с памятью, инструментами, обработкой банковских
выписок и каналом связи.

Курс повторяет архитектуру реального проекта «Личный помощник» — супервизор
+ агенты-помощники (финансы, дела) с памятью (SQLite + заметки), инструментами
(function calling) и каналами (Telegram / веб-чат).

## Что получится в конце

Работающий личный ассистент, который умеет:

- отвечать на вопросы и помнить факты о пользователе;
- вызывать инструменты (function calling);
- читать учебную банковскую выписку и показывать сводку по категориям;
- отвечать в Telegram или веб-чате;
- хранить секреты в `.env`, делать бэкапы и работать по расписанию.

## Структура репозитория

| Путь | Что это |
|---|---|
| `course_program.md` / `.txt` | программа курса: цели, содержание, логика нарастания |
| `01…12_*.md` / `.txt` | 12 занятий (теория → демонстрация → практика) |
| `workbook.md` / `.txt` | рабочая тетрадь: таблицы результатов практик |
| `final_work.md` / `.txt` | итоговый проект и критерии оценки |
| `files/` | учебные материалы: вымышленная выписка, шпаргалки, заготовки кода, шаблоны `.env` |

Каждое занятие существует в двух форматах: **`.md`** (рендерится на GitHub)
и **`.txt`** (простой текст для скачивания/печати). Содержимое одинаковое.

## Как проходить

1. Начните с [`course_program.md`](course_program.md) — это карта курса.
2. Проходите занятия по порядку `01 → 12`. Сложность нарастает, пропускать
   нельзя — каждое занятие опирается на предыдущее.
3. Заполняйте [`workbook.md`](workbook.md) сразу после практики.
4. В конце соберите итоговый проект по [`final_work.md`](final_work.md).

**Главное правило курса:** код пишет слушатель, модель лишь помогает.
Умение прочитать сообщение об ошибке и починить свой код — половина результата.

## Что понадобится

- компьютер (Windows / macOS / Linux);
- Python 3.11+ и редактор кода (рекомендуется Visual Studio Code);
- доступ в интернет;
- для занятий 4–12 — модель. Два варианта:
  - облачный **NeuralDeep** ([neuraldeep.ru](https://neuraldeep.ru)) —
    OpenAI-совместимый API, модель `qwen3.8-27b`, ключ в личном кабинете;
  - локальная **Ollama** ([ollama.com](https://ollama.com)) — бесплатно,
    модель работает на вашем компьютере, ключ не нужен.

Выбор делается в файле `.env`: если есть ключ `NEURALDEEP_API_KEY` — работает
облако, нет — локальная Ollama.

## Учебные данные

Все компании, фамилии, суммы и номера счетов в материалах курса **вымышлены
и обезличены**. Настоящие выписки и персональные данные в учебный код не
подставляются. Секреты (ключи, пароли) хранятся только в файле `.env` и никуда
не публикуются.
