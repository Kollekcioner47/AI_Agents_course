ШПАРГАЛКА ПО ЗАНЯТИЮ 2: ТИПЫ, ОПЕРАТОРЫ, F-СТРОКИ, RANGE, INPUT/PRINT
========================================================================

ТИПЫ ДАННЫХ
------------------------------------------------------------------------
  str    строка, текст      "Алексей", "3000"    (в кавычках)
  int    целое число         3, -7, 3000          (без кавычек)
  float  дробное число       2.5, -0.75           (с точкой)
  bool   логическое         True, False           (с большой буквы)

Узнать тип:

    type("320")   →  <class 'str'>
    type(320)     →  <class 'int'>
    type(2.5)     →  <class 'float'>
    type(True)    →  <class 'bool'>

Перевод между типами:

    int("3000")    →  3000       строка в целое число
    float("2.5")   →  2.5        строка в дробное число
    str(320)       →  "320"      число в строку

ОПЕРАТОРЫ СРАВНЕНИЯ
------------------------------------------------------------------------
    ==    равно               !=    не равно
    <     меньше              >     больше
    <=    меньше или равно    >=    больше или равно

Логические связки:

    and   «и»    — оба условия верны
    or    «или»  — хотя бы одно верно

F-СТРОКИ
------------------------------------------------------------------------
Буква f перед кавычками, значения в фигурных скобках:

    name = "Алексей"
    age = 30
    print(f"Меня зовут {name}, мне {age} лет")

Меня зовут Алексей, мне 30 лет

RANGE
------------------------------------------------------------------------
    range(5)         числа 0, 1, 2, 3, 4
    range(1, 6)      числа 1, 2, 3, 4, 5        (от, до — не включая)
    range(0, 10, 2)  числа 0, 2, 4, 6, 8        (от, до, шаг)

INPUT / PRINT
------------------------------------------------------------------------
    print("Привет!")           выводит текст
    print("Всего:", 320)       выводит несколько значений через пробел
    name = input("Имя? ")      спрашивает, ВСЕГДА возвращает строку

ВНИМАНИЕ: input всегда возвращает str. Для счёта переводите:

    spend = int(input("Сумма: "))
    rate  = float(input("Курс: "))
