МАТЕРИАЛЫ ЗАНЯТИЯ 3 «ФУНКЦИИ И ФАЙЛЫ»
====================================================================

СОСТАВ КАТАЛОГА
--------------------------------------------------------------------

  primer.txt  — учебный файл для чтения. Десять строк формата
                «дата;сумма;описание», части разделены точкой с запятой.
                Все компании и суммы вымышлены.
  spravka.txt — шпаргалка: методы строк, чтение и запись файлов,
                кодировка.
  README.txt  — этот файл.

КАК ПОЛЬЗОВАТЬСЯ
--------------------------------------------------------------------

  1. Положите каталог files/03_funkcii_faily внутрь папки проекта
     assistant (рядом с файлами .py, которые вы пишете).

  2. Запускайте код из папки assistant. Путь к файлу в коде указывайте
     от этой папки: Path("files/03_funkcii_faily/primer.txt").

  3. primer.txt — только для чтения. Ничего в него не записывайте:
     write_text() перезапишет файл и сотрёт исходник. Результат пишите
     в новый файл result.txt.

  4. Если встретили ошибку UnicodeDecodeError — проверьте, что в
     read_text() или open() указан encoding="utf-8".

  5. Сверяйтесь со spravka.txt, когда забыли синтаксис метода или
     функции. Это шпаргалка, а не материал для заучивания.

ПРИМЕР СТРОКИ ИЗ primer.txt
--------------------------------------------------------------------

    03.09.2026;-1284.50;PYATEROCHKA 1234

Разбивается методом split(";") на три части:

    ['03.09.2026', '-1284.50', 'PYATEROCHKA 1234']
