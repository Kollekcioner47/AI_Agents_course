ШПАРГАЛКА ЗАНЯТИЯ 3: СТРОКИ И ФАЙЛЫ
====================================================================

МЕТОДЫ СТРОК
--------------------------------------------------------------------

  line.split(";")
      Режет строку line по разделителю «;» и возвращает список частей.
      "03.09.2026;-1284.50;PYATEROCHKA 1234".split(";")
      -> ['03.09.2026', '-1284.50', 'PYATEROCHKA 1234']

  line.strip()
      Убирает пробелы и символы переноса "\n" по краям строки.
      "  hi\n".strip() -> "hi"

  line.replace("старое", "новое")
      Заменяет все вхождения «старое» на «новое».
      "a,b".replace(",", ";") -> "a;b"

  line.lower()
      Делает все буквы строчными.
      "PYATEROCHKA".lower() -> "pyaterochka"

  ИНДЕКСАЦИЯ (нумерация с нуля):
      parts = line.split(";")
      parts[0]  — первая часть (дата)
      parts[1]  — вторая часть (сумма)
      parts[2]  — третья часть (описание)

ЧТЕНИЕ ФАЙЛА
--------------------------------------------------------------------

  Весь файл одной строкой (рекомендуется):
      from pathlib import Path
      text = Path("путь/к/файлу.txt").read_text(encoding="utf-8")
      lines = text.splitlines()      # список строк без "\n"
      print(len(lines))              # сколько строк

  Построчно через open():
      with open("путь/к/файлу.txt", encoding="utf-8") as f:
          lines = f.readlines()      # список строк, каждая с "\n" на конце

ЗАПИСЬ ФАЙЛА
--------------------------------------------------------------------

  from pathlib import Path
  Path("result.txt").write_text("текст\n", encoding="utf-8")

      Если файла нет — создаст. Если есть — перезапишет целиком,
      старое содержимое исчезнет.

  Собрать список строк в текст с переносами:
      "\n".join(список) + "\n"

КОДИРОВКА
--------------------------------------------------------------------

  encoding="utf-8" указывайте в read_text(), write_text() и open()
  всегда, когда в файле есть русские буквы. Без него на Windows
  может выскочить UnicodeDecodeError.
