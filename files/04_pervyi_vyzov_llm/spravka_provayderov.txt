ШПАРГАЛКА: ПРОВАЙДЕРЫ МОДЕЛЕЙ
Курс «Личный ИИ-помощник», занятие 4
=====================================================================

На занятии 4 ассистенту нужен «мозг» — языковая модель. Есть два
пути: облачный NeuralDeep (нужен API-ключ) или локальная Ollama
(бесплатно, модель работает на вашем компьютере). Код ассистента
одинаковый для обоих — меняются только base_url и имя модели.

---------------------------------------------------------------------
ВАРИАНТ A. NEURALDEEP: ПОЛУЧИТЬ API-КЛЮЧ
---------------------------------------------------------------------

  1. Откройте в браузере neuraldeep.ru и зарегистрируйтесь
     (подойдёт вход по почте).
  2. Войдите в личный кабинет (Dashboard): адрес neuraldeep.ru/app.
     Там же видны тарифы и лимиты. Есть бесплатный тариф Free — для
     первых занятий его достаточно; при желании можно выбрать платный
     тариф или пополнить кошелёк.
  3. В личном кабинете найдите раздел с API-ключами (API Keys).
  4. Создайте ключ и дайте ему имя (например, assistant).
  5. Скопируйте появившийся ключ. Он выглядит как длинная строка,
     начинающаяся со sk-. Ключ показывают ПОЛНЫМ только один раз —
     сразу скопируйте его в файл .env.

  Куда вписать ключ — в файл .env, строка NEURALDEEP_API_KEY=...

  ВАЖНО: ключ — это пароль от вашего счёта. Не отправляйте его в чат
  с моделью, не кладите в код и не публикуйте. Если ключ утёк —
  удалите его в личном кабинете и создайте новый.

---------------------------------------------------------------------
ВАРИАНТ B. OLLAMA: ПОСТАВИТЬ ЛОКАЛЬНУЮ МОДЕЛЬ
---------------------------------------------------------------------

Ollama — бесплатная программа, которая запускает модель прямо на
вашем компьютере. Интернет нужен только чтобы её скачать, дальше
модель работает без сети и без ключа.

  1. Скачайте установщик для вашей системы с сайта ollama.com.
  2. Установите программу как обычное приложение.
  3. Проверьте, что Ollama запущена: на Windows — значок в системном
     трее, либо в терминале выполните команду ollama serve (окно
     не закрывайте).
  4. В новом окне терминала скачайте модель:

         ollama pull qwen3:8b

     Первая загрузка занимает несколько минут и пару гигабайт —
     это нормально.
  5. Проверить, что модель на месте, можно командой:

         ollama list

  Настройки для файла .env (вариант B):

         OLLAMA_BASE_URL=http://127.0.0.1:11434/v1
         OLLAMA_MODEL=qwen3:8b

  Для Ollama ключ не нужен — строка api_key в коде остаётся пустой.

---------------------------------------------------------------------
ЧТО ТАКОЕ BASE_URL И МОДЕЛЬ
---------------------------------------------------------------------

  BASE_URL — адрес, по которому программа находит сервер с моделью.
    * у NeuralDeep это https://api.neuraldeep.ru/v1 (сервер в интернете);
    * у Ollama это http://127.0.0.1:11434/v1 (ваш же компьютер;
      127.0.0.1 значит «этот компьютер», 11434 — порт, на котором
      Ollama слушает запросы).

  МОДЕЛЬ — какая именно нейросеть отвечает на запрос.
    * qwen3.8-27b — модель NeuralDeep;
    * qwen3:8b — модель Qwen на 8 миллиардов параметров, которую
      скачали через Ollama. Имя должно совпадать с тем, что вернула
      команда ollama list.

  ENDPOINT — последняя часть адреса /chat/completions. Он одинаковый
  у NeuralDeep и Ollama (обе понимают «OpenAI-совместимый» формат),
  поэтому один и тот же код chat() работает с обоими провайдерами.

---------------------------------------------------------------------
КАК ВЫБРАТЬ
---------------------------------------------------------------------

  * Нет возможности платить или нет стабильного интернета — берите
    Ollama: бесплатно и работает офлайн.
  * Хотите быстрый старт и качество облачной модели — берите NeuralDeep:
    настройка проще, но нужен ключ и баланс.

В любой момент можно переключиться: достаточно поменять строки в
файле .env. config.py сам выберет NeuralDeep, если есть ключ, и Ollama,
если ключа нет.
