ШПАРГАЛКА ПО SQL (занятие 6)
=======================================================================

SQL — язык запросов к базе данных SQLite. Ниже команды, которые нужны
на занятии. Ключевые слова запроса пишутся латиницей, а сами значения
могут быть русскими.

СОЗДАТЬ ТАБЛИЦУ
-----------------------------------------------------------------------
    CREATE TABLE IF NOT EXISTS profiles (
        section TEXT,
        key TEXT,
        value TEXT,
        PRIMARY KEY(section, key)
    )

  * section — раздел (например «факты»);
  * key — ключ (например «имя»);
  * value — значение (например «Алексей»);
  * PRIMARY KEY(section, key) — пара «раздел + ключ» не повторяется;
  * IF NOT EXISTS — не ломается, если таблица уже есть.

ДОБАВИТЬ СТРОКУ
-----------------------------------------------------------------------
    INSERT INTO profiles(section, key, value) VALUES(?, ?, ?)

  * значения подставляются вместо знаков «?» отдельным списком;
  * вклеивать значения как текст в запрос НЕЛЬЗЯ — только через «?».

ЗАПОМНИТЬ ИЛИ ОБНОВИТЬ (одной командой, «upsert»)
-----------------------------------------------------------------------
    INSERT INTO profiles(section, key, value) VALUES(?, ?, ?)
    ON CONFLICT(section, key) DO UPDATE SET value=excluded.value

  * если пары «раздел + ключ» нет — строка добавится;
  * если есть — значение обновится, дубликата не появится.

ПРОЧИТАТЬ ОДНУ СТРОКУ
-----------------------------------------------------------------------
    SELECT value FROM profiles WHERE section=? AND key=?

  * возвращает строку из одной колонки value;
  * если ничего не найдено — пустой результат (None в Python).

ПРОЧИТАТЬ ВСЕ СТРОКИ
-----------------------------------------------------------------------
    SELECT section, key, value FROM profiles ORDER BY section, key

  * возвращает все строки, отсортированные по разделу и ключу.

ИЗМЕНИТЬ СТРОКУ (если нужно именно обновить)
-----------------------------------------------------------------------
    UPDATE profiles SET value=? WHERE section=? AND key=?

ПАМЯТКА: в Python запрос выполняется так — значения вторым аргументом:

    con.execute("SELECT value FROM profiles WHERE section=? AND key=?", ("факты", "имя"))

После INSERT или UPDATE обязательно вызовите con.commit(), иначе
изменения не попадут в файл базы.
