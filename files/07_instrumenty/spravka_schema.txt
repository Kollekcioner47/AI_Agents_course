ШПАРГАЛКА: JSON-СХЕМА ИНСТРУМЕНТА
=======================================================================

Инструмент описывается для модели как словарь с двумя полями:
"type" и "function". Внутри "function" — имя, описание и параметры.

    {
        "type": "function",
        "function": {
            "name": "current_time",
            "description": "Текущее время на компьютере в формате ЧЧ:ММ.",
            "parameters": {
                "type": "object",
                "properties": {},
                "required": []
            }
        }
    }

ПОЛЕ ЗА ПОЛЕМ
-----------------------------------------------------------------------
  type        — всегда "function". Говорит модели, что это вызов функции.
  function    — конверт, внутри которого всё описание инструмента.
  name        — имя функции в вашем Python-коде. Модель возвращает его
                в tool_calls, а dispatch по нему выбирает, что выполнить.
  description — что инструмент делает. Чем точнее, тем вернее модель
                решит, когда его вызывать. Пишите для постороннего:
                не «посчитать», а «считает выражение из чисел и + - * /».
  parameters  — описание аргументов, которые инструмент принимает.
      type        — всегда "object" (параметры передаются объектом).
      properties  — словарь параметров: имя -> {type, description}.
      required    — список имён обязательных параметров. Если их нет,
                    оставьте пустым списком [].

ПАРАМЕТР ИНСТРУМЕНТА
-----------------------------------------------------------------------
Если у инструмента есть аргумент, он описывается в properties:

    "parameters": {
        "type": "object",
        "properties": {
            "expression": {
                "type": "string",
                "description": "Выражение, например '2 + 3 * 4'."
            }
        },
        "required": ["expression"]
    }

ТИПЫ ПАРАМЕТРОВ
-----------------------------------------------------------------------
  "string"  — текст;
  "integer" — целое число;
  "number"  — число (может быть дробным);
  "boolean" — истина/ложь (true/false).

ПРАВИЛА
-----------------------------------------------------------------------
  1. name в схеме обязан совпадать с именем функции в Python — иначе
     dispatch не найдёт её.
  2. required перечисляет только обязательные параметры. Если параметр
     необязательный — не включайте его в required.
  3. description пишется простыми словами: модель читает его как
     инструкцию, когда решает, нужен ли инструмент.
  4. Пустые параметры — это parameters = {"type": "object",
     "properties": {}, "required": []}.
