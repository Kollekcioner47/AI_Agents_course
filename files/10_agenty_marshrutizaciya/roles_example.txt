Готовый образец ролей для занятия 10. Три агента: Фёдор (финансы),
Вера (дела), Ася (прочее). Копировать не нужно: набирайте руками
и сверяйтесь. Все имена и примеры вымышлены.

----------------------------------------------------------------------
КЛАСС AGENT
----------------------------------------------------------------------

Это цикл «мысль → действие» из занятия 7, упакованный в класс. Каждый
агент получает свои name, system_prompt, tools и необязательный context
(сводку передаём ещё одним системным сообщением):

    import json
    import llm
    from tools import dispatch, TOOLS_BY_NAME


    class Agent:
        def __init__(self, name, system_prompt, tools=None):
            self.name = name
            self.system_prompt = system_prompt
            self.tools = tools or []

        def run(self, user_msg, context=None):
            messages = [{"role": "system", "content": self.system_prompt}]
            if context:
                messages.append({"role": "system",
                                 "content": "Контекст: " + context})
            messages.append({"role": "user", "content": user_msg})
            schemas = [TOOLS_BY_NAME[name] for name in self.tools]
            for _ in range(8):
                msg = llm.chat(messages, tools=schemas or None)
                if not msg.get("tool_calls"):
                    return msg.get("content") or ""
                messages.append(msg)
                for tc in msg["tool_calls"]:
                    name = tc["function"]["name"]
                    args = json.loads(tc["function"].get("arguments") or "{}")
                    result = dispatch(name, args)
                    messages.append({
                        "role": "tool",
                        "tool_call_id": tc.get("id", ""),
                        "content": result,
                    })
            return "Не удалось получить ответ."

    def build_agents():
        return {key: Agent(role["name"], role["system_prompt"], role["tools"])
                for key, role in ROLES.items()}

----------------------------------------------------------------------
ЧТО ДОЛЖНО БЫТЬ В tools.py
----------------------------------------------------------------------

Agent.run берёт схемы инструментов по имени из TOOLS_BY_NAME, поэтому
в tools.py нужна одна строка:

    TOOLS_BY_NAME = {t["function"]["name"]: t for t in ALL_TOOLS}

Инструмент finance_summary должен быть в ALL_TOOLS (со схемой) и в
dispatch. Если его ещё нет, поставьте заглушку (см. README.txt).

----------------------------------------------------------------------
ПРАВИЛА
----------------------------------------------------------------------

  1. name — это имя, которым агент представляется в ответе.
  2. description пишется простыми словами: по нему модель решает,
     какому агенту отдать вопрос.
  3. system_prompt задаёт узкую роль: кто агент, о чём отвечает,
     откуда берёт цифры, каким тоном.
  4. tools — имена инструментов, доступных только этому агенту.
  5. Нового агента добавляют новой записью в ROLES — build_agents
     и супервизор подхватят его сами.
