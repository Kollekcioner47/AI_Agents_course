МАТЕРИАЛЫ ЗАНЯТИЯ 11: КАНАЛЫ
=======================================================================

В этом каталоге три файла:

  README.txt        — этот файл.
  requirements.txt  — зависимости для ДВУХ вариантов канала. Ставить
                      нужно только один, по выбранному каналу.
  index_web.html    — готовая самодостаточная HTML-страница веб-чата.
                      Отправляет сообщение и пароль fetch-запросом на
                      /api/chat и печатает ответ.

КАК ПОЛЬЗОВАТЬСЯ
-----------------------------------------------------------------------
  1. Откройте занятие 11_kanaly.txt.
  2. В части 1 (теория) разберите, зачем канал и как выбрать вариант.
  3. В части 2 (демонстрация) смотрите, как преподаватель собирает
     веб-чат целиком: web.py, index_web.html, ограничение паролем.
  4. В части 3 (практика) выберите канал, установите зависимости из
     requirements.txt и напишите свой web.py или telegram_bot.py.
  5. Заполните таблицу 11 в workbook.txt.

ВЫБОР КАНАЛА
-----------------------------------------------------------------------
  * Веб-чат (fastapi + uvicorn) — рекомендуется: проще, без токена бота.
    Установка:  pip install fastapi uvicorn
  * Telegram-бот (aiogram) — мобильно, с уведомлениями, нужен токен.
    Установка:  pip install aiogram

ОСТОРОЖНО
-----------------------------------------------------------------------
Токен Telegram (TELEGRAM_BOT_TOKEN), пароль веб-чата (WEB_PASSWORD) и
ключи владельца (OWNER_TELEGRAM_ID, OWNER_TELEGRAM_USERNAME) хранятся
только в файле .env. В код и в этот каталог они не вписываются: в коде
остаётся только имя переменной, значение приходит из .env через config.py.
