ЧЕК-ЛИСТ БЕЗОПАСНОСТИ: ЗАПУСК АССИСТЕНТА В РАБОТУ
=====================================================================

Проходится перед переводом ассистента из учебного в рабочий.
Каждый пункт отмечайте [x] только тогда, когда он реально сделан.
Частично пройденный чек-лист не считается пройденным.

1. СЕКРЕТЫ
---------------------------------------------------------------------
  [ ] Ключи и пароли лежат только в файле .env, в коде их нет.
  [ ] Файл .env есть в .gitignore и НЕ попадает в git (проверено
      командой git status).
  [ ] В .env.example все значения пустые — шаблон можно показывать.
  [ ] Настоящий ключ не отправлялся в чат с моделью и не светился
      на скриншотах и демонстрациях.
  [ ] Пароль веб-чата задаётся ТОЛЬКО через .env: в config.py
      у паролей и ключей нет значений по умолчанию.

2. ДАННЫЕ И БЭКАПЫ
---------------------------------------------------------------------
  [ ] Папка data создана и содержит учебные данные (не реальные).
  [ ] Бэкап создан и открывается: внутри папка data и файл .env.
  [ ] Старые бэкапы очищаются: хранится не больше 7 версий.
  [ ] Бэкап с .env хранится так же бережно, как сам ключ: в своей
      папке, не в публичном облаке, никому не пересылается.

3. КАНАЛ И ДОСТУП
---------------------------------------------------------------------
  [ ] Канал отвечает только владельцу: Telegram проверяет
      OWNER_TELEGRAM_ID, веб спрашивает логин и пароль.
  [ ] Для будущей почты заведён белый список ALLOWED_SENDERS.
  [ ] Чужой пользователь не может писать ассистенту (проверено
      запросом с постороннего id или без пароля).

4. РАСПИСАНИЕ
---------------------------------------------------------------------
  [ ] Ежедневная задача записана в scheduler.py (сводка или проверка,
      что бот жив).
  [ ] Планировщик проверен на коротком интервале (60 секунд) и
      возвращён на сутки (86 400 секунд).
  [ ] Понятно, как остановить цикл (Ctrl+C) и как запустить снова.

5. ЗАПУСК И ПРОВЕРКА
---------------------------------------------------------------------
  [ ] Ассистент запускается одной командой без ручных правок.
  [ ] Задан тестовый вопрос — ассистент ответил без ошибок.
  [ ] В рабочей тетради заполнены таблица 12 и сводная страница курса.
